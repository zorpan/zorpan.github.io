## 30.1 手写简易版 Spring IoC 容器

```java
public class MiniApplicationContext {
    private final Map<String, Object> beanMap = new ConcurrentHashMap<>();
    private final Map<String, BeanDefinition> beanDefinitions = new HashMap<>();

    public void scan(String basePackage) {
        // 1. 扫描 @Component 注解的类
        // 2. 解析为 BeanDefinition
        // 3. 创建实例并注入依赖
    }

    public Object getBean(String name) {
        return beanMap.get(name);
    }

    private Object createBean(BeanDefinition definition) {
        // 反射创建实例
        Object instance = definition.getClazz().getDeclaredConstructor().newInstance();
        // 注入依赖（@Autowired）
        injectDependencies(instance);
        // 初始化（@PostConstruct）
        invokeInitMethod(instance);
        return instance;
    }
}
```

**核心知识点：** 反射、注解处理、依赖注入、生命周期管理。

## 30.3 手写简易版消息队列

```java
// Broker（消息存储）
public class MessageBroker {
    private final Map<String, Queue<Message>> topicQueues = new ConcurrentHashMap<>();

    public void send(String topic, Message message) {
        topicQueues.computeIfAbsent(topic, k -> new LinkedBlockingQueue<>())
                   .offer(message);
    }

    public Message poll(String topic, long timeout) {
        Queue<Message> queue = topicQueues.get(topic);
        return queue != null ? queue.poll(timeout, TimeUnit.MILLISECONDS) : null;
    }
}

// Consumer Group（消费者组）
public class ConsumerGroup {
    private final List<Consumer> consumers;
    private final AtomicInteger index = new AtomicInteger(0);

    public Consumer getNextConsumer() {
        // 轮询分配（使用 getAndUpdate 避免溢出）
        return consumers.get(index.getAndUpdate(i -> (i + 1) % consumers.size()));
    }
}
```

**核心知识点：** 消息存储、消费者组、负载均衡、持久化。

## 30.4 手写简易版连接池

```java
public class SimpleConnectionPool {
    private final BlockingQueue<Connection> pool;
    private final int maxSize;

    public SimpleConnectionPool(String url, String user, String pass, int size) {
        this.maxSize = size;
        this.pool = new ArrayBlockingQueue<>(size);
        for (int i = 0; i < size; i++) {
            pool.offer(DriverManager.getConnection(url, user, pass));
        }
    }

    public Connection getConnection(long timeout) throws Exception {
        Connection conn = pool.poll(timeout, TimeUnit.MILLISECONDS);
        if (conn == null) throw new RuntimeException("连接池耗尽");
        return conn;
    }

    public void releaseConnection(Connection conn) {
        if (pool.size() < maxSize) {
            pool.offer(conn);
        } else {
            conn.close();
        }
    }
}
```

## 面试精选

### 1. 手写 Spring IoC 需要哪些核心能力？

反射创建实例、注解扫描（@Component）、依赖注入（@Autowired）、Bean 生命周期管理（@PostConstruct/@PreDestroy）、BeanDefinition 解析。

### 2. 手写 RPC 框架的核心组件？

动态代理（客户端 Stub）、网络通信（Netty）、序列化（Protobuf/Kryo）、服务注册与发现（ZooKeeper/Nacos）、负载均衡、超时重试。

### 3. 为什么要手写中间件？

深入理解框架原理，面试中展示技术深度。手写过程中会遇到真实的设计问题（线程安全、性能优化、异常处理），这些经验能帮助更好地使用和排查开源框架。
