## 4.1 泛型类与泛型接口

### 4.1.1 泛型类

```java
public class Result<T> {
    private int code;
    private String message;
    private T data;

    public Result(int code, String message, T data) {
        this.code = code;
        this.message = message;
        this.data = data;
    }

    public T getData() { return data; }
}

// 使用
Result<String> stringResult = new Result<>(200, "ok", "hello");
Result<User> userResult = new Result<>(200, "ok", new User());

// 菱形推断（JDK 7+）
Result<String> result = new Result<>(200, "ok", "hello");
```

### 4.1.2 多类型参数

```java
public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }
}

Pair<String, Integer> pair = new Pair<>("age", 25);
```

### 4.1.3 泛型接口

```java
public interface Repository<T, ID> {
    T findById(ID id);
    List<T> findAll();
    void save(T entity);
}

// 实现方式 1：指定具体类型
public class UserRepository implements Repository<User, Long> {
    @Override
    public User findById(Long id) { return null; }
}

// 实现方式 2：保留泛型
public class JpaRepository<T, ID> implements Repository<T, ID> {
    @Override
    public T findById(ID id) { return null; }
}
```

## 4.2 泛型方法与类型推断

### 4.2.1 泛型方法

```java
// 泛型方法：<T> 声明在返回值之前
public static <T> T getFirst(List<T> list) {
    return list.get(0);
}

// 泛型方法的类型参数独立于泛型类
public class Utils {
    // 这个 T 与类的 T 无关
    public static <T> List<T> asList(T... elements) {
        List<T> list = new ArrayList<>();
        for (T e : elements) list.add(e);
        return list;
    }
}

// 使用
String s = getFirst(Arrays.asList("a", "b", "c"));  // 类型推断为 String
List<Integer> nums = Utils.asList(1, 2, 3);          // 类型推断为 Integer
```

### 4.2.2 类型推断

```java
// 编译器根据参数自动推断类型
public static <T> T of(T value) { return value; }

String s = of("hello");      // 推断 T = String
Object o = of("hello");      // 推断 T = Object（赋值目标类型也参与推断）

// 多个泛型参数时可能需要显式指定
public static <T, R> R convert(T input, Function<T, R> func) {
    return func.apply(input);
}

// 类型推断失败时需要显式指定
String result = MyClass.<Integer, String>convert(123, Object::toString);
```

## 4.3 通配符与 PECS 原则

### 4.3.1 三种通配符

```java
// 1. 无界通配符 <?>：接受任意类型
public void printList(List<?> list) {
    for (Object item : list) {
        System.out.println(item);  // 只能读为 Object，不能写
    }
}

// 2. 上界通配符 <? extends T>：T 或 T 的子类（协变）
public double sum(List<? extends Number> list) {
    double total = 0;
    for (Number n : list) {
        total += n.doubleValue();  // 可以读为 Number
    }
    return total;
    // 不能 add（不知道具体是哪个子类型）
}

// 3. 下界通配符 <? super T>：T 或 T 的父类（逆变）
public void addNumbers(List<? super Integer> list) {
    list.add(1);         // 可以 add Integer 及其子类
    list.add(2);
    Object obj = list.get(0);  // 只能读为 Object
}
```

### 4.3.2 PECS 原则

**Producer Extends, Consumer Super**

```java
// 如果你要从集合中读取数据（Producer），用 <? extends T>
public void copy(List<? extends T> src, List<? super T> dest) {
    for (T item : src) {     // src 是生产者，用 extends
        dest.add(item);       // dest 是消费者，用 super
    }
}

// 经典例子：Collections.copy()
public static <T> void copy(List<? super T> dest, List<? extends T> src)
```

| 通配符 | 读 | 写 | 场景 |
|--------|----|----|------|
| `<? extends T>` | 可以读为 T | 不能写（除了 null） | 生产者（提供数据） |
| `<? super T>` | 只能读为 Object | 可以写 T 及子类 | 消费者（接收数据） |
| `<?>` | 只能读为 Object | 不能写 | 不关心类型 |

## 4.4 类型擦除的本质与限制

### 4.4.1 类型擦除

```java
// 编译后泛型信息被擦除，替换为上界（默认 Object）
List<String> strings = new ArrayList<>();
List<Integer> integers = new ArrayList<>();
System.out.println(strings.getClass() == integers.getClass()); // true！

// 编译后的字节码（擦除后）
List strings = new ArrayList();
List integers = new ArrayList();
```

**擦除规则：**
- `<T>` → `Object`
- `<T extends Number>` → `Number`
- `<T extends Comparable & Serializable>` → `Comparable`（取第一个边界）

### 4.4.2 类型擦除带来的限制

```java
// 1. 不能用基本类型作为类型参数
List<int> list;     // 编译错误
List<Integer> list; // 正确

// 2. 不能 instanceof 泛型类型
if (list instanceof List<String>) { }  // 编译错误
if (list instanceof List<?>) { }       // 可以

// 3. 不能创建泛型数组
T[] array = new T[10];             // 编译错误
T[] array = (T[]) new Object[10];  // 可以，但有 unchecked 警告

// 4. 不能对泛型类型使用 class 字面量
Class<T> clazz = T.class;  // 编译错误

// 5. 不能在静态上下文中使用类型参数
public class Box<T> {
    private static T value;  // 编译错误！静态成员不持有泛型信息
}
```

### 4.4.3 桥接方法（Bridge Method）

```java
class Parent<T> {
    public T get() { return null; }
}

class Child extends Parent<String> {
    @Override
    public String get() { return "hello"; }  // 返回 String
}

// 编译器生成桥接方法：
// public Object get() { return (Object) this.get(); }
// this.get() 在字节码层面调用子类的 String get()，然后强转为 Object 返回
// 这样通过 Parent 引用调用 get() 时，也能正确执行 Child 的版本
```

## 4.5 泛型与反射的协作

```java
// 获取泛型父类的类型参数
public class UserRepository extends JpaRepository<User, Long> { }

Type genericSuperclass = UserRepository.class.getGenericSuperclass();
if (genericSuperclass instanceof ParameterizedType) {
    ParameterizedType pt = (ParameterizedType) genericSuperclass;
    Type[] typeArgs = pt.getActualTypeArguments();
    Class<?> entityClass = (Class<?>) typeArgs[0];  // User.class
    Class<?> idClass = (Class<?>) typeArgs[1];       // Long.class
}

// 这就是 Spring Data JPA、MyBatis 等框架获取泛型实体类型的方式
```

## 面试精选

### 1. Java 泛型的类型擦除是什么？有什么影响？

泛型是编译期特性，编译后泛型信息被擦除。`<T>` 替换为 Object，`<T extends Number>` 替换为 Number。影响：不能用基本类型作类型参数、不能 instanceof 泛型类型、不能创建泛型数组、运行时无法获取泛型信息。类型擦除是为了兼容 JDK 5 之前的代码。

### 2. `<? extends T>` 和 `<? super T>` 的区别？PECS 原则？

`<? extends T>` 上界通配符，只能读不能写（读为 T），适用于生产者；`<? super T>` 下界通配符，可以写 T 及子类、读为 Object，适用于消费者。PECS 原则：Producer Extends, Consumer Super。经典应用 `Collections.copy(List<? super T> dest, List<? extends T> src)`。

### 3. `List<String>` 和 `List<Integer>` 在运行时有区别吗？

没有。由于类型擦除，`List<String>.class == List<Integer>.class` 为 true。泛型信息只存在于编译期，运行时都是原始类型 `List`。这就是为什么不能 `instanceof List<String>`，只能 `instanceof List<?>`。

### 4. 泛型方法和泛型类有什么区别？

泛型类在实例化时指定类型参数，整个类中可以使用该类型；泛型方法在调用时推断类型参数，方法级别的类型独立于类。泛型方法更灵活，不需要依赖类的泛型声明，且可以通过参数自动推断类型。静态方法不能使用类的泛型参数，但可以定义自己的泛型参数。

### 5. 为什么不能创建泛型数组？

因为数组在运行时知道元素类型（`ArrayStoreException` 检查），但泛型在运行时被擦除，无法保证类型安全。如果允许 `new T[10]`，实际创建的是 `new Object[10]`，往里放入错误类型不会在数组层面报错，但取出来转型时会出错。
