面试精选

1. Maven 依赖冲突怎么解决？

最短路径优先、先声明优先、exclusion 排除冲突版本、dependencyManagement 锁定版本。mvn dependency:tree 查看依赖树定位冲突。

2. Git Flow 和 Trunk-Based 的区别？

Git Flow 分支多、流程规范但复杂，适合发版周期长的项目。Trunk-Based 主干开发、短生命周期分支，适合持续部署的互联网团队。推荐 Trunk-Based + CI/CD。
