8.1.2 Class 对象的唯一性

每个类在 JVM 中只有一个 Class 对象。Class 对象在类第一次被加载时由 JVM 创建，存放在方法区（JDK 8 是永久代，JDK 9+ 是元空间 Metaspace）。

8.3 反射性能分析与优化

8.3.1 反射为什么慢？

主要原因：

  1. 方法查找：每次 getMethod() 都要遍历方法表
  2. 安全检查：每次调用都要进行权限验证
  3. 无法内联：JIT 编译器无法对反射调用做内联优化

8.3.2 优化方案

面试考点：Spring 中是怎么优化反射性能的？
Spring 对频繁使用的反射做了缓存：ReflectionUtils 缓存了方法和字段查找结果；CachedIntrospectionResults 缓存了 Bean 的属性信息；AOP 代理对象创建后缓存了 Method 对象。

8.5 CGLIB 动态代理

8.5.1 原理

CGLIB 通过生成目标类的子类来实现代理，不需要目标类实现接口。

8.5.2 JDK 动态代理 vs CGLIB

特性 JDK 动态代理 CGLIB
原理 基于接口（实现接口） 基于继承（生成子类）
要求 目标类必须实现接口 目标类不能是 final
性能 创建快，调用略慢 创建慢，调用快
final 类/方法 可以代理 不能代理
Spring 默认 有接口时使用 无接口时使用（Spring Boot 2.x+ 默认 CGLIB）

面试考点：Spring AOP 用的是哪种代理？
Spring 5.x：默认使用 JDK 动态代理（有接口时）或 CGLIB（无接口时）。Spring Boot 2.x+：默认强制使用 CGLIB（proxyTargetClass=true），因为 CGLIB 不要求目标类实现接口，使用更统一。可以通过 @EnableAspectJAutoProxy(proxyTargetClass=false) 切换回 JDK 代理。

8.6 字节码操作

8.6.1 ASM

  • 底层字节码操作框架，直接操作 JVM 指令
  • 性能最好，但 API 复杂
  • 被 CGLIB、Groovy、Kotlin 编译器等底层使用

8.6.2 Javassist

  • 源码级别的字节码操作，可以用 Java 代码字符串生成类
  • 使用简单，性能比 ASM 差
  • Hibernate、MyBatis 使用

8.6.3 Byte Buddy

  • 高级字节码生成库，API 友好
  • Spring Boot、Jackson、Mockito 内部使用

面试精选

1. 反射的用途？框架中怎么用反射的？

用途：动态创建对象、动态调用方法、动态读写字段、获取注解信息。框架应用：Spring IoC 通过反射创建 Bean 实例；MyBatis 通过反射将查询结果映射到 POJO；Jackson 通过反射序列化/反序列化 JSON；JUnit 通过反射调用测试方法。

2. 反射为什么慢？怎么优化？

慢的原因：方法查找开销、安全检查开销、无法 JIT 内联。优化方案：缓存 Method/Field 对象（避免重复查找）、调用 setAccessible(true)（跳过安全检查）、使用 MethodHandle（JDK 7+，性能接近直接调用）。Spring 对频繁使用的反射做了多级缓存。

3. JDK 动态代理和 CGLIB 的区别？

JDK 动态代理基于接口，代理类实现目标接口，通过 InvocationHandler 转发方法调用，要求目标类实现接口；CGLIB 基于继承，生成目标类的子类，通过 MethodInterceptor 拦截方法调用，目标类不能是 final。Spring Boot 2.x+ 默认使用 CGLIB。

4. 什么是动态代理？有哪些应用？

动态代理是在运行时动态创建代理类，无需手动编写代理代码。应用：Spring AOP（事务管理、日志、权限校验）、RPC 框架（客户端代理发起远程调用）、MyBatis Mapper 接口代理（接口方法映射到 SQL 执行）。

5. Class.forName() 和 ClassLoader.loadClass() 的区别？

Class.forName() 会执行类的初始化（执行 static 块），ClassLoader.loadClass() 只加载不初始化。Class.forName(“com.mysql.Driver”) 会执行 Driver 类的 static 块（注册驱动），这是 JDBC 4.0 之前手动注册驱动的方式。

6. 为什么说反射破坏了封装性？

反射可以通过 setAccessible(true) 访问 private 字段和方法，绕过了访问控制。这也是为什么单例模式推荐枚举实现——枚举天然防反射攻击，因为反射无法创建枚举实例。序列化也可以通过反射创建对象，枚举同样可以防御。
