手写中间件：IoC、RPC、消息队列

发表于 2026-06-22 更新于 2026-06-28 分类于 Java 进阶之路

本文是「Java 进阶之路」系列的一部分，聚焦实战与面试。

30.1 手写简易版 Spring IoC 容器

核心知识点： 反射、注解处理、依赖注入、生命周期管理。

30.2 手写简易版 RPC 框架

核心知识点： 动态代理、Netty 网络编程、序列化、服务注册发现。

30.3 手写简易版消息队列

核心知识点： 消息存储、消费者组、负载均衡、持久化。

30.4 手写简易版连接池

面试精选

1. 手写 Spring IoC 需要哪些核心能力？

反射创建实例、注解扫描（@Component）、依赖注入（@Autowired）、Bean 生命周期管理（@PostConstruct/@PreDestroy）、BeanDefinition 解析。

2. 手写 RPC 框架的核心组件？

动态代理（客户端 Stub）、网络通信（Netty）、序列化（Protobuf/Kryo）、服务注册与发现（ZooKeeper/Nacos）、负载均衡、超时重试。

3. 为什么要手写中间件？

深入理解框架原理，面试中展示技术深度。手写过程中会遇到真实的设计问题（线程安全、性能优化、异常处理），这些经验能帮助更好地使用和排查开源框架。
