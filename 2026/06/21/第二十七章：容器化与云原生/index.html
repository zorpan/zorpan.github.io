Docker 与 Kubernetes 云原生实战

发表于 2026-06-21 更新于 2026-06-25 分类于 Java 进阶之路

本文是「Java 进阶之路」系列的一部分，聚焦实战与面试。

27.1 Docker 基础

Docker 核心概念：

  • 镜像（Image）：只读模板，分层存储
  • 容器（Container）：镜像的运行实例
  • Dockerfile：构建镜像的脚本
  • Docker Compose：多容器编排

27.2 Kubernetes 核心概念

核心资源：

资源 说明
Pod 最小部署单元，一个或多个容器
Deployment 管理 Pod 副本、滚动更新
Service 服务发现和负载均衡
Ingress HTTP 路由（域名→Service）
ConfigMap 配置管理
Secret 敏感信息管理

27.3 云原生 12 要素

面试精选

1. Docker 和虚拟机的区别？

Docker 容器共享宿主机内核，启动快（秒级），资源占用少。虚拟机有独立内核，启动慢（分钟级），资源占用大。容器隔离性不如虚拟机，但性能更好。

2. K8s 的核心概念？

Pod（最小部署单元）、Deployment（管理副本和滚动更新）、Service（服务发现和负载均衡）、Ingress（HTTP路由）。Master 负责调度和管理，Node 负责运行容器。

3. 怎么实现零停机部署？

K8s 滚动更新（Rolling Update）：逐步替换旧 Pod，设置 maxSurge 和 maxUnavailable。配合 readinessProbe（就绪探针）确保新 Pod 就绪后再接收流量。优雅终止：preStop hook + SIGTERM 处理。
